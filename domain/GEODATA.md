# Границы районов Новосибирска

`novosibirsk-districts.geojson` — локальный снимок десяти районов, полученный
2 ноября 2026 года из OpenStreetMap через Nominatim (`search`, `polygon_geojson=1`).
ID исходной OSM relation указан в свойствах каждой геометрии. Границы используются
для подсказки; пользователь подтверждает район или выбирает его вручную.

Источник: © участники [OpenStreetMap](https://www.openstreetmap.org/copyright),
лицензия [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/).
При обновлении набора запрашивайте только названия районов, соблюдайте
[политику Nominatim](https://operations.osmfoundation.org/policies/nominatim/)
и проверяйте все десять геометрий. Координаты пользователей для этого не нужны.

Во время работы бота геокодер и другие внешние картографические API не вызываются.
Координаты обрабатываются в памяти; FSM и база получают только название района.
